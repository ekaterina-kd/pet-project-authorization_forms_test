# Pet Project: Автотесты для формы авторизации
**Проект содержит автоматизированные тесты для проверки формы авторизации веб-приложения.**

**Стек:** Java, Maven, TestNG, Selenide, SLF4J Simple, Selenium DevTools.

## Тесты покрывают:
* ✅ Отображение элементов формы авторизации
* ✅ Корректность цветов элементов формы авторизации
* ✅ Отображение подсказок в полях формы авторизации
* ✅ Валидацию полей электронной почты и пароля
* ✅ Отображение ошибок при некорректном вводе 
* ✅ Изменение цвета кнопок при наведении курсора
* ✅ Изменение цвета полей ввода при некорректном вводе
* ✅ Сброс введенных значений в поля формы авторизации
